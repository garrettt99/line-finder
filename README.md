# Line Finder

Pregame odds comparison and estimated expected value (EV) dashboard in a single HTML file.

**Open it:** https://garrettt99.github.io/line-finder/

- Starts on a simulated feed with fictional sportsbooks.
- For live odds, get a free key at the-odds-api.com and paste it under **Model & data**. The key stays in your browser.
- Estimated EV is an estimate of long-run return, not a guarantee.
