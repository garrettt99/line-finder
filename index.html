What is EV?

  

    

      
EV means expected value. It's roughly how much you'd win or lose on average per $100 if you made the same bet many times.

    

    
How Line Finder works it out

      
    
        
  1. Find the real chance. It looks at the same bet at the other sportsbooks and removes their built-in cut (the "vig"). What's left is a fair estimate of how often the bet wins. The book being rated is left out, so it never grades its own price.
    2. 
        
  2. Compare it to the price on offer. If a book pays more than that fair chance deserves, the bet has positive EV.
    3. 
      

    
Example

      

        
The other books, with their cut removed, say a team wins about 50% of the time. A fair price is +100. One book is offering +110.

        

          
Half the time you win+$110

          
Half the time you lose−$100

          
Average per $100 bet+$5 → +5.0% EV

        

        
If that book only offered −110, the average would be about −$4.50, a negative EV bet.

      

    
Reading the board

      
    
        
  • +EVPositive EV. The price beats the market's fair estimate. Worth a closer look.
    • 
        
  • Fair oddsFair odds. What the price would be with no cut taken. Better than this is +EV.
    • 
        
  • Best priceBest price. The best number any book has. It isn't automatically +EV, because sometimes every book is bad.
    • 
        
  • ReviewNeeds review. The EV looks too good to be true, often a stale or mistaken price. Check before betting.
    • 
        
  • Your pricePrice you see at. If the book's price has moved, type it into the wager's detail panel and EV recalculates. A small move can flip a bet from positive to negative.
    • 
      

    
EV is an average over many bets, not a promise. A +3% bet still loses often. It's an estimate built from what the other books think, so it shows where the value probably is, not a sure thing.

  






  
About Line Finder

  

    
Workflow

      
  1. Find an opportunity. The board ranks each exact wager by the offer with the highest estimated EV. Suspicious offers go to Needs review instead.
    2. 
        
  2. Compare the offers. Open a row to see every book's price for that exact wager.
    3. 
        
  3. Verify the estimate. Check the exact selection, line, period and price, type the price you see at the book, and Line Finder recalculates EV at that price.

    
What depends on the feed

      
    
        
  • Quote timestamps. Ages come from the provider's own quote time. When the feed sends none, Line Finder shows "Quote age unknown" and doesn't rank the quote.
    • 
        
  • Settlement rules. Not supplied by The Odds API. Live quotes stay "Settlement rules unverified" and out of cross-book EV until you record a verified rule (source and review date) under Settings & key.
    • 
        
  • Sportsbook links. Only when the feed provides one. A link is shown only if its address matches the sportsbook's known website.
    • 
        
  • Exchange commission. Not supplied by any feed. You set each exchange's rate. Until then, exchange quotes show raw prices and no net EV.
    • 
        
  • Line history. Simulated in the demo. Live history builds only from prices observed between fetches.
    • 
        
  • Second feed. Not configured. Each quote records its source; a second feed would pass the same matching and freshness checks.
    • 
      

    
Connect a licensed feed

      
The page reads odds through one adapter object. Replace DemoOddsAdapter with your own and pass it to startApp().


class MyFeedAdapter {
  id = 'myfeed'; label = 'My licensed feed'; isDemo = false;
  minIntervalMs = 60000;      // refresh cooldown
  rules = {};                 // verified settlement rules
  async load() {   // first snapshot
    return { books: [{ id, name, exchange }],
             events: [{ id, sport, league, away, home,
                        awayId, homeId, as, hs, start }],
             offers: [{ src, book, eventId, type, period,
                        settlement /* or null */, line,
                        status, updated /* provider ms or null */,
                        outcomes: [{ id, label, line }],
                        prices: [-110, -110],
                        links: { event, outcomes } }] };
  }
  async poll() {   // later updates: offers array
    return [/* changed offers */];
  }                // throw { status, transient, retryAfterMs }
}                  // on failure so retries back off correctly
startApp(new MyFeedAdapter());

    A gap is measured in implied-probability points against the median of the other books' quotes for the same outcome. Flagged prices are also left out of everyone else's reference set.
    
      
    
    
    
    
    Exchange commission
    
      
    Effective odds = 1 + (posted − 1) × (1 − commission), for a standalone back bet. Results are labelled as estimates. You supply the rate; feeds don't.
    
      
    
    
    
    
    Settlement rules
    
      
    Quotes are compared across books only when each book's rule for that league, market and period is stated by the feed or recorded here with a source and review date. Rules are never guessed from market names. The Odds API doesn't state them.
